# Рабочие рамки трипваеров (синтез ресёрча, 2025-2026)

Свод из 8+ источников. Опорный материал для скилла product-unpack.

## 1. Что делает трипваер конверсионным
- Трипваер продаёт СМЕНУ СТАТУСА (лид → покупатель), не выручку. Повторная покупка у трипваер-клиента 60-70% против 5-20% у холодного.
- Один результат, одно «до/после». Узкое обещание конвертит выше широкого.
- Instant-win: результат за минуты-часы, не «когда пройду».
- Воспринимаемая ценность сильно выше цены (якорит готовность платить за флагман).
- Мост к флагману зашит внутрь: решение трипваера обнажает следующую проблему.
- Бесшовная покупка (один тап), подлинный дефицит на 2 касания.
- Бенчмарки: конверсия в трипваер 15-25%, апгрейд трипваер→основной ≥20%.

## 2. Распаковка экспертизы в оффер
- **Value Ladder:** free (магнит) → low-ticket (трипваер, standalone-инструмент) → mid (курс/тулкит) → high (флагман). Каждая ступень усиливает боль следующей. Проектировать от флагмана назад.
- **Value Equation (Хормози):** Ценность = (Мечта-результат × Вера) / (Задержка × Усилия). Продукт двигает верх вверх, низ вниз. Продавать результат клиента, не контент («первые заявки без съёмок», не «20 промптов»).
- **Hook-Story-Offer:** хук дословной болью → история-мост → оффер = обещание. Боль хука = обещание = содержимое.
- **One problem / one promise + MVO:** одна проблема, одно обещание; минимальный набор выгод, достаточный для продажи, проверяемый спросом.

## 3. Форматы (формат = физическая форма боли)
- Набор промптов/AI-пак: ниша AI/контент, «результат за вечер», режет усилия.
- Заполненный шаблон: боль «чистый лист».
- Чек-лист С МЕХАНИКОЙ: риск пропустить шаг (только с действиями внутри, не темы).
- Воркбук: нужна проработка руками.
- Playbook/система: повторяемая методология, лучший мост к флагману.
- Мини-курс (1 навык): навык требует показа ($49-499).
- Notion/планировщик: боль «нет структуры».
- Swipe-файл: копирайт/скрипты.
- Дефолт под инфо-эксперта в AI-нише: набор промптов ИЛИ playbook.

## 4. Цена
- Коридор доверия low-ticket ~$27-97 (в рублёвом инфо-сегменте нижние сотни рублей — верх первой тысячи). Слишком дёшево ($9.99) = 78% abandonment против 41% у $47, сигналит «мусор».
- Charm-цена (не круглая, левая цифра): $47 ближе к $40. Charm обгоняет round на ~24%.
- Якорь поднимает воспринимаемую ценность ~32%: «часть курса за X, отдельно за Y».
- Цена = функция контекста/позиционирования, не себестоимости.
- Трипваер = charm; флагман = можно round как сигнал качества.

## 5. Признаки слабого трипваера (провал инфо-продуктов ~87%)
- Вода вместо инструмента; оглавление вместо содержимого.
- Promise-mismatch (обещал одно, внутри другое) → возвраты.
- Commodity без угла; underpricing из страха; нет instant-win; широкое обещание.
- Гейт: «получил результат, прочитав только это?» + «сохранил бы, вот это сильно?» — оба «да».

## 6. Валидация спроса до сборки (платят кошельком, не словами)
1. Контентные сигналы (сохранения, «где взять») — первый бесплатный фильтр.
2. Опрос ЦА — слаб для спроса, силён для языка боли.
3. MVP/кусок как платный тизер.
4. Пре-продажа — сильнейший сигнал (HBR: пре-сейл до +60% успеха).
5. Waitlist/лендинг.
- «Купят»: органические сохранения/репосты, вопросы «где купить», платят за костыли-заменители, waitlist наполняется.
- «Не купят»: лайкают, но не сохраняют и не спрашивают; на опросе «интересно», но без контакта/предоплаты.
