# Визуал-стек агентства (ежедневная генерация)

Порядок выбора инструмента: сначала бесплатный codex-image-gen, точное лицо — face-swap поверх, Higgsfield только для видео/фото-сессий (платные кредиты, спросить агента-кодера).

## 1. Картинки — codex-image-gen (бесплатно, gpt-image-2)

```bash
python3 ~/bin/codex-image-gen.py \
  --prompt "<ДЕТАЛЬНЫЙ арт-промпт: субъект + сцена по теме + свет + стиль>" \
  [--ref-image <фото.jpg>] [--quality low|medium|high] \
  [--aspect square|landscape|portrait] --out result.png
```

Правила (из практики куратора):
- НЕ передавать короткую фразу. Разверни в детальный художественный промпт (кадр, свет, сцена, стиль) — так работает ChatGPT внутри. Лучше 2-3 варианта, выбрать глазами.
- Запускать ТОЛЬКО синхронно (foreground). nohup/фон рвёт SSE: HTTP 200, но файл не пишется.
- `--ref-image` даёт ПОХОЖЕГО человека, НЕ 1:1. Кириллицу в картинке рисует хорошо, но шрифт гуляет; для бренд-серий текст накладывать поверх (PIL/рендер).
- Токен машинный (`~/.codex/auth.json`), авто-обновляется watchdog'ом. 401 token_revoked — сказать агенту-кодеру.

## 2. Точное лицо 1:1 — face-swap поверх генерации

```bash
~/var/venvs/faceswap/bin/python ~/bin/face-swap-cover.py \
  --source <реальное_фото_лица.jpg> --target <генерация.png> --out result.png
```

- Интерпретатор строго `~/var/venvs/faceswap/bin/python` (там cv2+insightface; системный python3 упадёт на ImportError).
- source = чёткое фронтальное фото; на target одно лицо (при нескольких свапится крупнейшее). ~25 сек CPU.
- Пайплайн обложки: codex-image-gen (сцена + похожий человек) → face-swap (точное лицо) → готово.

## ПРАВИЛА ТЕКСТА (HARD, разбор СММ проекта 07.08.2026, распоряжение оператора)

До того как писать хоть строку для людей, прочитай целиком
`~/.claude/skills/_text-rules/TEXT_RULES.md`. Короткая выжимка, чтобы
правила работали даже если файл не открыл:

1. Никаких «Где здесь X и где Y» и «это не про X, это про Y». Плюс прежние запреты: длинное
   тире «—» и оборот «не X, а Y».
2. Живая русская речь. Каждую фразу проверь вопросом «так вообще говорят?». «Часть дружб
   заканчивается» это брак, «часть друзей перестаёт общаться» нормально.
3. Пункт списка это конкретная ситуация целиком, без абстракций. Читатель должен понимать,
   с кем встреча, что отменяем, кто кого избегает.
4. Отсылок назад нет: «как я писала выше», «вернусь к» запрещены, каждый слайд понятен сам.
   Петля ведёт ВПЕРЁД, следующий слайд её закрывает.
5. Термин вводится сразу с расшифровкой, иначе не используется вовсе.
6. Финал и лид-магнит вытекают из разобранного механизма, случайный «просто чтобы был» это брак.
7. Перед выдачей прогони чек-лист из §7 файла: вслух, абстракции, самодостаточность слайда,
   связь финала, вычистка «—» и пар из п.1.

## 3. Карусели (recreate-pipeline)

Формат: **4:5, 1080x1350**, один PNG на слайд. Пайплайн рекрейта чужой виральной карусели:
1. Разбор исходника: выписать текст КАЖДОГО слайда полностью (текст не сокращать), понять структуру (cover → контент-слайды → CTA).
2. Канон дизайна — скилл `carousel-reskinner` (SKILL.md, секция «ДИЗАЙН РЕКРЕЙТА»): исходник = база, улучшить до премиума без радикального рестайла; НЕ вся серия в одном дизайне; заголовки ровными строками 2-4 слова, левое выравнивание; чужие ники → свой аккаунт клиента; лицо знаменитости в новости оставлять.
3. Рендер ТОЛЬКО браузером (PIL-шрифты забракованы оператором, gpt-image ломает длинную кириллицу):
   - `python3 ~/bin/carousel_render.py spec.json out_dir/` — чистый стиль, Onest, авто-подгон кегля (текст никогда не режется). Пример спеки: `~/bin/carousel-render/test_car1.json`.
   - `python3 skills/visual-gen-howto/scripts/notebook_render.py spec.json out_dir/` — рукописный стиль «синяя ручка на крем-бумаге» (Caveat). Типы слайдов: cover | prompts | note | cta.
   - Схема спеки у обоих рендеров: объект `{"handle": "@аккаунт", "slides": [...]}` (НЕ голый список). Текст слайда в note/cta лежит в поле `text` (не body) — незнакомые поля рендер молча игнорирует, слайд выйдет пустым.
4. **QC по-слайдно (обязательно)**: каждый PNG открыть через Read глазами — текст влез целиком, ничего не обрезано, выравнивание ровное, тире «—» и контрасты «не X, а Y» вычищены. Только потом отдавать.

Текст поверх фото: PIL 12.2 стоит системно; шрифты в `~/.fonts` (Montserrat Black = фирменный вес).

## 4. Сторис / хайлайты (1080x1920)

`python3 skills/visual-gen-howto/scripts/stories_neon_render.py spec.json out_dir/ [--scale 2]` — вертикальный неон-рендер (headless Chrome, чистая кириллица). Типы слайдов в спеке: cover / cover_photo (фон = генерация codex-image-gen) / story / case (ДО→ПОСЛЕ) / cta. QC по-слайдно как у каруселей.

## 5. Премиум видео/фото — Higgsfield (ПЛАТНО, под гейтом)

Скиллы `higgsfield-generate`, `higgsfield-soul-id`. Жгут ЖИВЫЕ кредиты с баланса оператора.
- Вызывать ТОЛЬКО через обёртку: `~/bin/higgsfield-gated <команды CLI>` — она логирует расход по агентам (`~/var/log/higgsfield-usage.log`) и алертит оператора при большом расходе. Голый `higgsfield` не звать.
- Перед первым использованием спросить агента-кодера через gbrain-swarm: есть ли кредиты и одобрен ли расход. Сейчас на аккаунте free plan, 0 кредитов — генерация не пройдёт, пока оператор не пополнит.

## Границы

- Данные клиентов/операторские фото — только в своём scope, между воркспейсами не таскать.
- Нет нужного инструмента — вопрос агенту-кодеру через swarm, не оператору.
