## 10. Токены для генератора (обязательный блок, добавлен 30.07)

Разделы выше читает человек. Этот блок читает КОД: `carousel_lib.brand()` парсит его и отдаёт
готовый CSS. Пока значения лежат только в прозе, каждый сборщик рисует по своей копии, и стиль
клиента расходится по авторам. Замер 30.07 по команде: design.md был у семи агентов, машинно не
читался ни один, при этом палитра дублировалась в скриптах, от 2 до 29 файлов на агента.

Значения здесь ТЕ ЖЕ, что в таблицах §2 и §3. При расхождении прав этот блок, потому что
рисует он.

```json
{
  "canvas": { "w": 1080, "h": 1350, "safe": 60, "footer_bottom": 64 },
  "qc": { "min_body_fs": 30, "min_hook_cover": 0.55 },
  "surfaces": {
    "main": {
      "bg": "TODO_hex",
      "bg_alt": "TODO_hex",
      "text": "TODO_hex",
      "text_muted": "TODO_hex",
      "accent": "TODO_hex",
      "headline_font": "TODO_face",
      "body_font": "TODO_face",
      "label_font": "TODO_face",
      "digit_font": "TODO_face"
    },
    "alt": {
      "bg": "TODO_hex",
      "bg_alt": "TODO_hex",
      "text": "TODO_hex",
      "text_muted": "TODO_hex",
      "accent": "TODO_hex",

  "footer": { "handle": "TODO_client_handle", "swipe": "листай →", "last": "почти всё →" }

```

**Как проверять, что гейт живой** (этот приём сильнее простого прогона):
скопируй свой заполненный файл во временную копию, подмени в ней ОДИН цвет обратно на `TODO_hex`
и убедись, что сборка падает и называет ИМЕННО ЭТОТ путь. И отдельно: если мутация не нашла
цель для подмены, тест обязан упасть, иначе он ничего не доказывает. Прогон на заполненном файле
показывает только, что файл заполнен, а не что гейт работает.

**Гейт машинный, не на дисциплине.** Незаполненное значение роняет сборку с перечислением путей.
Причина инженерная: заглушка это невалидный цвет, браузер молча её игнорирует, слайд выходит
почти правильным и уезжает в ленту. Лучше падающая сборка, чем тихая. Заполнять значениями
клиента, палитру чужого клиента не копировать даже как отправную точку.

**Гейт судит ровно то, что рисует.**
Общие блоки (`canvas`, `qc`, `type_scale`, `footer`) проверяет `brand()`, конкретную поверхность
проверяет `surface(name)`. У меня сначала весь файл судился целиком, и заглушка в поверхности,
которой эта сборка вообще не рисует, валила её полностью. Такой отказ учит снимать гейт вместо
того, чтобы заполнять токены, а это ровно обратное тому, ради чего он ставился. Незаполненное в
общих блоках блокирует всё по-прежнему: `footer` и `qc` читают все сборки.

**Незаполненное это не только `TODO_`.** Пустая строка, `null` и число тоже проходили насквозь и
доезжали до CSS видом `background:;color:None`, то есть браузер молча брал своё. Ловится теперь
всё это, отдельной проверкой обязательных цветов.

**Ещё три способа получить МОЛЧА чужую палитру, все закрыты, знать о них надо.** Блок токенов
опознаётся по ключу `surfaces`, а не берётся первым по порядку: `design.md` это документ для
людей, и пример выше настоящих токенов становился палитрой бренда. Свой пример для человека
помечай ```jsonc, тогда он не спутается с рабочим блоком; два блока с `surfaces` это отказ.
Незакрытый блок больше не съедает следующий вместе с настоящими токенами. Поиск файла вверх по
каталогам стопорится на каталоге с `.claude`, иначе сборка клиента могла подхватить чужой
`design.md` этажом выше.

**Как потребляет код:**

```python
import carousel_lib as cl
CSS = cl.brand_css("main")   # переменные и базовые классы, без своих хексов в скрипте
```

Проверка себя:

```bash
grep -rniE '#[0-9a-f]{6}|\(\s*[0-9]{1,3}\s*,\s*[0-9]{1,3}\s*,\s*[0-9]{1,3}\s*\)' \
  --include='*.py' .claude | grep -v design.md | wc -l
```

**Вторая половина регулярки нужна обязательно, её отсутствие это типовая ошибка.**
Первая версия искала только хекс, а PIL-рендеры задают цвет кортежем `(214, 170, 92)`, и на них
проверка давала честный ноль при полностью разошедшейся палитре. У неё так и было: золото в трёх
версиях обложки стояло `(214,170,92)`, то есть `#D6AA5C` вместо канонного `#D0B068`, подсветка
разъехалась на четыре разных значения, фон и текст тоже мимо канона. Кортежная часть даёт ложные
срабатывания на любых тройках чисел, и это осознанный размен: ложная тревога стоит одного взгляда,
ложное «чисто» стоит разъехавшегося бренда.

Ноль тут не самоцель. Сборщики уже отданных наборов переводятся по мере СЛЕДУЮЩИХ сборок, живое
ради стиля не пересобирается. Долг записывается числом с именами файлов, чтобы он был виден.

**Свои ключи заводить можно.** `brand_css` выносит в CSS-переменные любой ключ поверхности со
значением-цветом, это свойство намеренное. Заводить новый ключ следует, когда у цвета ДРУГАЯ РОЛЬ
(подсветка градиента против акцентной кнопки), а не когда просто другой оттенок той же роли.
Подмена по похожести оттенка это брак, ловится только на живом прогоне.

**Цифры это отдельное решение от букв.** В декоративной гарнитуре цифра читается как другой
знак: в декоративной гарнитуре четвёрка выглядит как «Ч», шестёрка как «б» (ловится на живой
карусели). Буквы можно декоративной, цифры нейтральной, и обязательно там, где число означает
деньги, метраж или срок. Авто-QC этого не видит: текст влез, кегль в норме, а цена читается
другая.

**`footer.handle` это handle ТОЙ поверхности, где публикуемся.** Телеграм-слаг в подвале
инстаграм-карусели читается как инстаграм-ник, которого у клиента нет, и трафик уходит
постороннему. Случай живой, не гипотетический. Поверхность публикации подтверждать вопросом
клиенту, а не догадкой.
