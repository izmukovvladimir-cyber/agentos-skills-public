# Client-facing professional report template (forward-ready)

Use this AFTER `report.json` is produced when the operator wants a clean,
**forward-ready** report to paste into a client / work chat (not the internal
verdict notes). Professional but human language — no internal jargon, no
"наша кухня", no slang. Validated format (владелец, "более
профессионально, человеческим языком, чтобы переслать в рабочий чат").

Deliver as ONE self-contained message so it can be forwarded alone.

## Structure

```
📊 Анализ YouTube-канала «<Название>» (@<handle>, <Имя автора>)
<дата> · разбор топ-роликов по виральности

Обзор канала
<подписчики> · <всего роликов> (<Shorts>/<длинных>) · медианный просмотр — <median> · суммарно <views_total>.

Что работает
<2-4 пункта общего паттерна топ-видео: тип заголовка-крючка, механика payoff,
формат (Shorts/скетч/история). Конкретно, без воды.>

Зоны роста
1. <дыра №1 — обычно «нет закреплённого формата»: объём против медианы>
2. <дыра №2 — дрейф от рабочей механики / смена формата без причины>
3. <дыра №3 — незадействованные ресурсы: пустые описания, нет CTA-воронки>

Топ-5 (виральность = кратность к медиане)
Для каждого: «×<кратность> · <просмотры> — «<заголовок>»
<что сработало, 1 строка>. → <ВЕРДИКТ ЗАГЛАВНЫМИ>
<ссылка>

Рекомендация
<1 абзац: какую связку зафиксировать и системно повторять.>
```

## Вердикты — жёсткие лейблы (стандарт)
В клиентском пакете вердикт по каждому ролику ставить ОДНИМ заглавным лейблом,
жирным, в конце строки «что сработало». Это решительно и сразу читается:
- **СКОПИРОВАТЬ** — формат и тема переносятся как есть.
- **АДАПТИРОВАТЬ** — формат рабочий, тему свапнуть под нишу.
- **РАЗВИВАТЬ** — есть механика/потенциал, нужно докрутить (хук/CTA).
- **ПРОПУСТИТЬ** — не ориентир (слабый/нерелевантный/неповторимый).
НЕ сглаживать вердикт в прозу — теряется острота (проверено: сглаженная
версия  проиграла версии с лейблами). Структура — чистая
форвард-версия, вердикты — жёсткие. Это канон пакета.

## Правила тона
- Профессионально, но живым языком. Без канцелярита и без сленга.
- Виральность = кратность к медиане канала (× median), а не абсолют — так виден реальный отрыв.
- Вердикты переводить в действие для клиента: «масштабировать / адаптировать темы / развивать формат / не ориентир».
- НЕ критиковать ролики за «не в нише» — front-end виралка намеренно широкая (правило «контент ≠ продукт»).
- Никаких внутренних данных агентства, цифр владельца, имён команды.

## Внутренняя версия (для своих, НЕ форвардить)
Параллельно держать `report_final.md` с полем «вердикт» по 4-шкале
(Скопировать / Адаптировать / Изучить и развить / Пропустить) + 1-line why —
это рабочая разметка, не для клиентского чата.
