# animated-carousel

Путь собран на реальной карусели «ИИ-команда» (5 видео-слайдов). Пример ТЗ целиком:
`templates/brief_example_ai_team.md`. Готовый результат складывай в
`<WORKSPACE>/assets/montage/<тема>_motion_<дата>/final/`.

Две главные ошибки первого прогона, из-за которых были правки и досылки:
1. Слово в призыве было занято чужой воронкой (кодовое слово уже вело на другой гайд).
2. Длинное слово не влезло в плитку (перенос в две строки, подпись срезана).
Обе ловятся ДО ТЗ шагом 1. Цель: комплект с первого раза.

Скрипты вызываются по пути установленного скилла: `SKILL_DIR=~/.claude/skills/animated-carousel`.
Нужны `bash`, `python3`, `ffmpeg`/`ffprobe`, `timeout` (coreutils).

## Шаг 0. Какой режим

| Что прислал | Режим | Как собирается |
|---|---|---|
| Видео-слайды донора, «такое же» | A. Повтор механики | Ритм и анимация донора, свои тексты, палитра, ник |
| Текст / тезисы / пост | B. Текст в движение | Тексты по строке, карточки, счётчики, полоски процесса |
| Картинки или нужен визуал | C. Картинки в движение | Кадры из генератора изображений (например, скилл `codex-image-gen`), движение HyperFrames (наезд, параллакс, появление текста) |
| Своя готовая статичная карусель (PNG-слайды) | D. Оживить свою | Слайды как фон, текст и элементы поверх кодом, появление по строке |

Нейросетевое видео годится только на переходы; точная графика и буквы только кодом в HyperFrames.
Видеогенераторы обычно не берут узнаваемых публичных людей. Лицо владельца только по его
референсам и с его согласия (см. скилл `synthetic-avatar`).

## Шаг 1. Проверки ДО ТЗ (блокирующие)

1. **Слово свободно или ведёт куда надо:** `GUIDES_REGISTRY=<реестр гайдов.json> bash "$SKILL_DIR/scripts/word_free.sh" СЛОВО`
   (с `FUNNEL_VERIFY=<путь к funnel_verify.py>` заодно проверит структуру воронки по слову).
   `EXACT` значит слово уже занято, `SIMILAR` только похожие слова: проверь глазами, куда они ведут.
   Нашлось живое слово с близким гайдом, значит берём ЕГО и пишем обещание слайда под этот гайд.
   Совпадения нет, значит новое слово, магнит и воронка по скиллу `funnel-under-codeword`.
   Обещание последнего слайда = содержание гайда, построчно.
2. **Палитра не та же, что в прошлой анимированной карусели.** Прошлую палитру записывай строкой
   сюда после сдачи (пример: чёрный #000 + золото #f7cb2b + фиолет #7c3aed).
3. **Длина строк под плитки:** в ТЗ задать явно: «самое длинное слово в плитке в одну строку, кегль
   уменьшай до влезания, плитки одинаковой высоты, подписи внутри плитки с отступом 24px от края».
4. **Тексты слайдов:** по своду правил живого текста (`_text-rules`): без длинных тире и контрастов
   «не X, а Y». Маскировка слов на картинке: «диpᴇкт» (латинская p, капитель ᴇ), «ком:ментарии»
   (зачем и как, см. `_text-rules`).

## Шаг 2. ТЗ на сборку

Структура по образцу `templates/brief_example_ai_team.md`: формат (число слайдов, 1080x1350,
длины по донору, без звука), механика анимации, палитра и шрифт, элементы (карточки/роли),
по каждому слайду заголовок с выделенной акцентом частью, тексты по порядку появления, низ.
Ник внизу слева, «NN/NN» справа, последние 1-2 с каждого слайда кадр стоит.

Собирает сам агент (HyperFrames, см. скилл `reels-montage`) или отдельный агент-монтажёр. Если
монтажёр отдельный, ТЗ уходит ему целиком одним сообщением через ваш канал между агентами, с
требованием: «Сдай ответом, назови АБСОЛЮТНЫЕ пути готовых файлов в final/, без временных
work-* путей». Донорские видео кладу на диск и пишу пути в ТЗ. Пришёл путь к временному файлу,
прошу готовый.

## Шаг 3. Приёмка по кадрам

```
bash "$SKILL_DIR/scripts/qa_frames.sh" <папка с mp4>
```
Смотрю КАЖДЫЙ `qa/*_end.jpg`: влезли ли слова, нет ли срезанных подписей, обещание
последнего слайда совпадает с гайдом, слово то же, что в капшене, число на заголовке сходится с
числом карточек. Формат 1080x1350, длины как в ТЗ. Брак возвращаю одной правкой на все слайды сразу.

## Шаг 4. Сдача владельцу

- Только ГОТОВЫЙ комплект после всех правок, все слайды по порядку одним сообщением.
  Досылки по одному слайду запрещены.
- Файлы копирую в `<WORKSPACE>/assets/montage/<тема>_motion_<дата>/final/`.
- Капшен отдельным сообщением в блоке кода: хук, 2-4 строки, призыв «Напиши «СЛОВО» мне в диpᴇкт,
  пришлю.», хвост «Написал в ком:ментариях и не пришло? Напиши в диpᴇкт сам, отправлю руками.»
  Перед отдачей прогони капшен по `_text-rules`.
- Воронка живая: `python3 "$FUNNEL_VERIFY" СЛОВО --live` (скилл `funnel-verify`) проходит целиком до отдачи.
- Выставляет владелец. Решение 2-4 строками в журнал решений агента.
