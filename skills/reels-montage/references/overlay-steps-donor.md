# reels-overlay-steps — оверлей-монтаж поверх живого видео

Эталонный проект (копировать композицию отсюда): `workspace/reels/overlay-0718/` от корня проекта,
если он есть в этой копии — иначе собирать по разделам ниже
(реф стиля — рилс «3 вещи после регистрации в Claude»; план: `plans/2026-07-18-reels-overlay-steps.md`).

## Пайплайн (10 шагов)

1. **Видео из бота.** Слушатель `scripts/reel-inbox.mjs` (long-poll, конфликтует с другими
   поллерами — стопать после приёма) или one-shot `engine/inbox-once.mjs` →
   `workspace/reels/_inbox/`. Лимит Bot API 20 МБ.
2. **Проба + лицо.** `ffprobe` (размер/длительность) + контактный лист
   `ffmpeg -vf "fps=1/6,scale=270:-1,tile=3x2"` → ГЛАЗАМИ определить safe-зоны:
   верх головы и подбородок в долях кадра. Стандарт для селфи 720×1280 → канвас 1080×1920:
   лицо ~y560–1190 → **карточки только y<540, караоке-пилюли y≈1290**. ЖЁСТКО: лицо не
   перекрывать ничем и никогда.
3. **Транскрипция word-level.** `python engine/transcribe_file.py <video> <out.json>` —
   faster-whisper small/int8, language=ru, выход `[{text,start,end}]`.
   **НЕ Parakeet**: media-use ставит его через parakeet-mlx (только Apple Silicon), на
   Windows недоступен. faster-whisper локальный и бесплатный. Числа/имена сверить на слух
   («2006»→«2026», «баню»→«банят» — whisper коверкает).
4. **Storyboard.** Разбить речь на биты: хук / панели-шаги / подтверждение / статы / CTA →
   `storyboard.json` (схема v3 talking-head-recut + faceSafeZone). Кодовое слово CTA — из
   речи. Типы строк панелей: chips | toggle | search | file | link | stat | confirm | buttons.
5. **Композиция.** Скопировать `public/index.html` эталона, заменить контент/тайминги.
   Дизайн-код: панель rgba(10,12,8,.92) + обводка #B9F040 + свечение; бейджи лайм/розовый;
   чипы с лаймовой рамкой; тумблеры GSAP (knob x+bg); каунт-апы (__fmtSp, пробел-разделитель);
   караоке-пилюли #0c0c0c/.9 груди; прогрессбар-градиент сверху; **нижний градиент-скрим**
   (div под оверлеями, над видео: linear-gradient прозрачный→rgba(0,0,0,.26) 48%→.52 100%,
   высота ~660px — заземляет кадр, контраст пилюлям); шрифт Montserrat
   ExtraBold/SemiBold TTF (кириллица!) в `public/fonts/` (репозиторий JulietaUla/Montserrat).
   Хук: наклонный лаймовый год + белый капс с чёрным строуком + **брендовая плашка с
   официальным SVG-лого** (лого: MCP `mcp__21dev__logo_search` или media-use
   `resolve --type logo` — svgl-каскад, оба без heygen). Эмодзи в строках — ок (реф так делает).
   Видео: `-g 30 -keyint_min 30` реэнкод в `public/input-video.mp4`, muted, звук вернём на миксе.
   **Грабля: у `.host` в CSS opacity:0 — в таймлайне включать И visibility, И opacity.**
6. **Линт.** `pnpm dlx hyperframes check public` — 0 errors обязательно.
   **`npx` в репо НЕ работает** (devEngines pnpm → EBADDEVENGINES) — только `pnpm dlx`.
7. **Снапшоты.** `pnpm dlx hyperframes snapshot public --at N` — работает только ОДИН --at
   за вызов (последний побеждает) + авто-кадр конца. Проверить глазами: хук, каждая панель
   в максимуме, пилюля, лицо чистое.
8. **Рендер.** `pnpm dlx hyperframes render public -o output.mp4 --fps 30` (~4 мин на 35с,
   лучше в фоне). Выход БЕЗ звука.
9. **Звук: голос + SFX-слой.** `engine/mix_audio.example.ps1` (скопировать в проект, править
   $events). **PS1 строго ASCII** (PS 5.1 читает UTF-8 без BOM как cp1251 — кириллица ломает
   парсер). SFX из media-use `audio/assets/sfx/` (если в копии скилла нет mp3 — забрать из
   raw.githubusercontent.com/heygen-com/hyperframes/main/skills/media-use/audio/assets/sfx/).
   Схема соответствий (громкости 0.3–0.65, голос всегда 1.0):
   | Событие | Звук |
   |---------|------|
   | Хук-слэм заголовка | impact-bass-1 (0.32) |
   | Вход/смена панели | whoosh-short (0.45) |
   | Чип / чёрная пилюля хука | pop (0.55) |
   | Тумблер ON | click (0.65) |
   | Старт каунтера | ping (0.35) |
   | Зелёный confirm-бар | chime (0.35) |
   | CTA-пилюля с кодовым словом | notification (0.40) |
   Караоке-пилюли БЕЗ звука (их 20+, будет каша). BGM: каталог требует heygen CLI (не
   установлен) — либо юзер даёт трек (замиксовать -20dB + sidechaincompress под голос),
   либо без музыки.
10. **QA + отправка.** `/watch` по final.mp4 (--no-whisper, кадров 24) — проверить синхрон
    и что лицо чистое. Отправка: inline node -e + FormData → sendVideo в чаты из
    `scripts/.telegram-config.json`. Потом хвост пайплайна CLAUDE.md §5 (гайд, воронка
    ChatPlace на кодовое слово, реестр).

## Медиа-возможности (media-use)

- **Лого брендов** — работает без heygen: `resolve --type logo` (svgl → simple-icons →
  favicon) или наш MCP 21dev. Вставлять инлайн-SVG в композицию.
- **SFX** — бандл 19 файлов (см. схему выше), manifest в `audio/assets/sfx/manifest.json`.
- **BGM / иконки / стоковые картинки** — требуют `heygen` CLI + авторизацию (пока НЕТ).
  Когда появится: иконки вместо эмодзи (`resolve --type icon`), картинки-вставки в панели
  (`resolve --type image`) — только где уместно, не перегружать.
- **Транскрипция media-use (Parakeet)** — только macOS/Apple Silicon. На Windows —
  faster-whisper (шаг 3).

## Правки после ревью (типовые)

- «Хук не цепляет» → крупнее, брендовая градиентная плашка с лого, наклон элементов,
  пульс scale 1→1.04 (repeat конечный, НЕ -1), эмодзи-акценты ☠️🚫 в пилюле.
- Палитру перекрашивать через :root переменные --lime/--pink.
- Тайминги правятся только в таймлайне (data-* хостов трогать при сдвиге окон).
