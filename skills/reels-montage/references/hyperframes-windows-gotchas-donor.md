# HyperFrames — окружение, вёрстка, врезки

Общее для ВСЕХ рилс-пайплайнов на HyperFrames: `social-talking-head-video`,
`reels-overlay-steps`, `figma-reels`, `vox-style-reels`, `talking-head-recut`.
Собрано 2026-08-02/03 на первой боевой сборке (`workspace/reels/test-multiki-0802`) —
половина пунктов стоила по 20-30 минут каждая.

## 1. Окружение: что сломано на этой машине

**`hyperframes init` НЕ РАБОТАЕТ.** Падает с `STATUS_STACK_BUFFER_OVERRUN` (0xC0000409)
на Node 25. Проверено на 0.7.60 и 0.7.88, с видео и без, из Git Bash и PowerShell,
прямым вызовом `dist/cli.js` — стека нет, падение нативного уровня. Обновление не лечит.

**Скаффолдить руками.** Шаблон — ОДИН файл:
`%APPDATA%\npm\node_modules\hyperframes\dist\templates\blank\index.html`.
Скопировать, подставить `data-duration` и `src`. `index.html` кладётся в КОРЕНЬ проекта
(не в `public/` — `check` ищет только в корне). Остальные команды работают:
`doctor`, `check`, `snapshot`, `remove-background`, `render`, `skills update`.

**ffmpeg подсовывать без кириллицы.** WinGet кладёт его в профиль пользователя, и если
в имени пользователя кириллица — HyperFrames такой путь не запускает. Держать копию
`ffmpeg.exe`/`ffprobe.exe` в коротком ASCII-пути и ставить его первым в PATH:
```powershell
$env:PATH = "<короткий ASCII-путь к ffmpeg\bin>;" + $env:PATH   # свой путь покажет: where ffmpeg
```

**`npx` из корня проекта падает** с `EBADDEVENGINES` — наш `package.json` требует pnpm.
Команды вроде `hyperframes skills update` запускать из нейтральной папки, ставятся глобально.
`hyperframes upgrade` интерактивен и в неинтерактиве висит — обновлять
`npm install -g hyperframes@latest`, тоже из нейтральной папки.

**Транскрипт свой.** `whisper-cpp` не установлен → `hyperframes transcribe` не работает.
Берём faster-whisper (`~/.claude/skills/vox-style-reels/engine/transcribe.py`), затем
конвертируем `words.json` из `[{w,s,e}]` в ожидаемый `[{text,start,end}]`.
Кириллица в stdout Windows бьётся — читать не вывод, а сам JSON.

**`group_transcript.py` из скилла для русского бесполезен:** функция выбора слова-акцента
режет всё кроме `[A-Za-z0-9]` и для кириллицы всегда возвращает последнее слово.
Группы и акценты расставлять вручную.

**`remove-background` очень медленный:** 25 с видео 1080×1920 = **29 минут** на CPU,
плюс первый запуск качает 176 МБ `u2net_human_seg.onnx`. **Запускать фоном первым делом**,
пока пишется композиция. `ffprobe` покажет `pix_fmt=yuv420p` — это НЕ значит, что альфы нет,
смотреть тег `ALPHA_MODE=1`.

**PowerShell режет список `--at`** — обязательно в кавычках: `--at "5.0,9.5,12.0"`,
иначе снимет только первый кадр. `python3` тут нет, только `python`.

## 2. Вёрстка: четыре бага, которые `check` проходит зелёным

**GSAP затирает центровку через `transform`.** Если элемент центрован
`left:50%; transform: translateX(-50%)`, а таймлайн анимирует ему `scale` — GSAP переписывает
всё свойство `transform`, сдвиг пропадает, подписи уезжают влево.
*Правильно:* внешний контейнер во всю ширину (`left:0; width:1080px; text-align:center`),
визуальная плашка — вложенный `inline-block`. Анимировать внешний.

**z-index обязателен, порядок в DOM не спасает.** Полноэкранная плашка с `z-index:6`
перекроет объявленные ПОСЛЕ неё элементы без своего z-index (auto = 0).
Так пропал весь текст врезки и шапка при наезде скриншота.

**Геометрию pop-out считать по кадру, а не на глаз.** Два захода мимо: сперва в карточку
попадал потолок, потом макушка легла НИЖЕ кромки и вылета не было вовсе.
Найти по снапшоту реальный Y макушки в исходнике, дальше:
```
scale   = max(w/sw, h/sh)
offset  = (sh*scale − h) * object-position-Y
media_y = source_y * scale − offset
```
Подобрать так, чтобы голова была на 40–140 px ВЫШЕ выреза `clip-path`.
Обрезается ТОЛЬКО подложка, слой-вырезка не трогается, геометрия у обоих идентичная —
иначе поедет контур.

**Подпись не класть на лицо** — держать выше карточки или на груди.

## 3. Чему доверять: HyperFrames ловит сам

- `timed_element_missing_clip_class` — без `class="clip"` элемент виден всю композицию.
- **StaticGuard**: затухание, упирающееся в старт следующего клипа, требует
  `tl.set(el,{opacity:0})` жёстким гашением, иначе перемотка оставит мёртвый кадр.
- **Контраст WCAG**: оранжевый на светлой стене дал 2.64:1 при норме 3:1 → подкладывать плашку.
- **`content_overlap` / `text_occluded`** — реально находит наезды блоков и уход текста
  под непрозрачный слой. Оба раза был прав.
- **Шрифты**: `Arial Black` рендерер молча подменяет на Montserrat. Писать Montserrat сразу,
  иначе превью и рендер разъедутся.

## 4. Врезки: реальные ассеты, а не типографика

Полноэкранная плашка с крупным текстом читается как заглушка. Первая версия была забракована
именно за это: «скучно, не хватает динамики, доп вставок изображений или схем, логотипов».

**Скриншоты живых страниц** —
`node scripts/shot-web.mjs <url> <out.png> [--w] [--h] [--scroll] [--wait] [--full]`
(headless Playwright, без логина, гасит куки-баннеры и консент).

**Скриншот 1:1 в вертикали нечитаем** — масштабировать группу до ~1.5 и вести панораму.

**Подсветки цифр класть ВНУТРЬ той же группы**, что и картинка, иначе при наезде они
сползут с того, что подсвечивают.

**Логотипы брендов:** сначала MCP `21dev` (`search_logo`), фолбэк — Simple Icons:
```bash
curl -sSL -o youtube.svg "https://cdn.simpleicons.org/youtube/FFF7EE"
```
Проверять размер файла: на 404 CDN отдаёт 0 байт, а curl молча создаёт пустышку.
Нет в наборе: `openai`, `chatgpt`, `runway`, `midjourney`, `capcut`.
Подробнее: [[feedback-logos-mcp21dev]].

**Схема вместо говорящей головы.** Бит, где спикер просто перечисляет инструменты, хорошо
превращается в цепочку с логотипами, въезжающими по одному, и линией между ними.

**Текст в зоне depth требует тёмного скрима** — слоновая кость по светлой стене не читается.
Строки делать блоками: инлайн-span при `line-height: 0.86` налезает на следующий.

## 5. Честность врезки (жёстко)

Врезка-доказательство обязана доказывать ровно то, что сказано. Три реальных случая:

- Канал из озвучки **не находился по расшифровке** — whisper переврал имя.
  Рисовать поддельный скриншот нельзя: искать первоисточник в `registry.json` и сценариях.
- Найденный реальный AI-канал имел **220 подписчиков и по 3–19 просмотров**. Поставить его
  рядом с фразой «55 миллионов просмотров» = соврать прямо в кадре. Скриншот удалён.
- Канал из сценария реален, но **наш собственный гайд, куда ведёт воронка, опровергает**
  тезис. Решение: скриншот ставим, но на этом бите на экране НЕТ спорного утверждения —
  только то, что видно на самой странице. См. [[reference-nunu-tv-claim-conflict]].

**Правило:** прежде чем ставить чужой узнаваемый бренд рядом с утверждением — проверить,
не опровергает ли это утверждение наш же гайд, на который ведёт воронка.

**Врезка не должна дублировать субтитр слово в слово.** Либо крупный текст несёт реплику
и мелкие субтитры в этот момент выключены, либо наоборот.

## 6. Процесс

1. `remove-background` — фоном, первым делом.
2. Транскрипт → почистить ошибки ASR, **тайминги не трогать**.
3. `BRIEF.md` с допущениями — особенно что НЕ пошло в кадр и почему.
4. Композиция → `hyperframes check`.
5. `hyperframes snapshot --at "..."` по всем битам → склеить в контактный лист и
   **посмотреть ГЛАЗАМИ**. Пройденный `check` не доказывает ни читаемость, ни клиренс лица,
   ни удачное кадрирование. Все четыре бага из раздела 2 нашлись только так.
6. Рендер `--quality high`, проверить длительность, звук и размер.
7. В бота: `node scripts/send-file-to-bot.mjs <file.mp4> "<подпись>"`.

## 7. Переходы HyperShader, скелеты, под-композиции (2026-08-09)

Источник: гайд `heygen-com/hyperframes` (`docs/guides/claude-design-hyperframes.md`,
копия — `tools/hyperframes-skeletons/GUIDE.md`) + разбор лонч-фильма
`hyperframes-launches/claude-design-send-hyperframes-launch`.
**Проверено рендером на этой машине** (hyperframes 0.7.88): mp4 с честным
WebGL-блендингом `cinematic-zoom`, тест — `D:\temp\hf-test-shader\`.

### Скелеты вместо сломанного init

`tools/hyperframes-skeletons/` — скаффолды с уже разведённым таймлайном, HyperShader
и autoAlpha-тумблерами (богаче, чем голый `blank/index.html`):
- `skeleton-a-social-reel/` — 1080×1920, 15с, 6 сцен, 1 шейдер на хиро (s3→s4);
- `skeleton-b-launch-teaser/` — 1920×1080, 25с, 8 сцен, 3 шейдера;
- C (объяснялка 45с) и D (кинематик 60с) — производные от B, рецепт в GUIDE.md.

Скелет пустой (сцены = FILL-комментарии), поэтому `check` на нём даёт **ложный
`sweep_static`** («timeline did not advance») — лечится наполнением сцен, это не бага.

### Правило 95% hard cuts

Шейдер-переход — только на 2–3 момента: хиро-реveal, слом энергии, CTA. Остальное —
жёсткие склейки, вход новой сцены делает всю работу. 14 шейдеров, подбор по энергии:
спокойное `cross-warp-morph`/`light-leak`/`domain-warp` · профи `cinematic-zoom`/
`whip-pan`/`sdf-iris` · агрессия `glitch`/`chromatic-split`/`ridged-burn` ·
мистика `gravitational-lens`/`ripple-waves`/`swirl-vortex`.
Тайминг: `time = граница_сцен − duration/2`; минимум 0.3с, норма 0.5с.
Запрещено: exit-твины перед шейдером (шейдер и есть выход) и «мостики»
`flash-through-white` по 0.01с.

### Грабля autoAlpha (сцена-невидимка)

При срабатывании шейдера HyperShader сбрасывает **всем** `.scene` `opacity:0`.
Отсюда два железных правила:
- **Non-anchor сцены** (не участвуют в шейдерах): `style="visibility:hidden"` +
  обязательные `tl.set("#sN",{autoAlpha:1},start)` и `tl.set("#sN",{autoAlpha:0},end)`.
  Именно `autoAlpha` — голый `visibility` не перебьёт сброшенный opacity.
- **Anchor-сцены**: `style="opacity:0"`, их opacity владеет HyperShader, autoAlpha
  НЕ трогать; но **первый anchor каждой группы** надо явно показать
  `tl.set("#sN",{opacity:1},start)` — сам он не появится.
Инвариант: `scenes.length === transitions.length + 1` в `HyperShader.init()`.

### Рендер: temp обязан жить на D

Рендерер меряет место в `C:\...\Temp` и **отказывается** при <1 ГБ (диск C у нас
хронически полон). Перед рендером:
```bash
export TEMP='D:\temp\hf-tmp' TMP='D:\temp\hf-tmp'
```
15с @ 1080×1920/30fps ≈ 74с рендера.

### Под-композиции: длинный ролик одним проектом

Как у лонч-фильма HeyGen: мастер-`index.html` — только слоты
`<div class="clip" data-composition-id="sN" data-composition-src="compositions/sN.html"
data-start=... data-duration=... data-track-index=N>` + пустой мастер-таймлайн.
Каждая глава — `<template>`-фрагмент со своим таймлайном в `compositions/`.
Один preview и один рендер на весь фильм — вместо наших 8 отдельных `hf-sN/`
со склейкой ffmpeg (как было в dom-levelsio).

**SFX кладут в корень**, не в под-композиции: `<audio>` с корневым-абсолютным
`data-start` (= старт главы + локальное время события). Каждому клику — **свой id и
свой track-index**, иначе слои режут друг друга; `<audio>` без id **молча выпадает
из рендера**. Файлы звуков брать с нулевым онсетом: тишина в начале файла = звук
опаздывает на кадры. Клик ставить на кадр НАЖАТИЯ (scale 0.90), не отпускания.

Референс-клоны обоих репо: `D:\temp\hf-refs\` (можно сносить, это копии).
