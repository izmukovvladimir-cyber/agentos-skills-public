```

По умолчанию Claude вас не знает. Создаём два файла:
ABOUT_ME.md — имя, цели, ваш опыт.
AI_STYLE.md — как вы хотите чтобы Claude думал, писал и действовал.
Эти файлы добавляются в каждый проект из дня 1.

День 3 — Claude работает сам.
Переключаемся на вкладку Code и подключаем Co-Work. Это режим где Claude выполняет задачи самостоятельно.
Промпт-инженеры берут за такую настройку 100 тысяч рублей. Я покажу как сделать в один клик: нажмите плюс → Skills → Setup Co-Work. Claude сам проведёт по инструкции.

День 4 — добавляем инструменты.
Кнопка «Кастомизация» → подключаем любые сервисы к Claude напрямую.

День 5 — раскрытие полного потенциала.
Включаем доступ Claude к компьютеру. Объём задач, который он может делать, вырастает в разы.

Полный гайд с командами и примерами — в статье. Напиши «статья» в ком:ментариях.
```

### ТЗ МОНТАЖЁРУ

- Длина: 90-100 сек
- Каждый «День X» — крупный оверлей текстом в начале блока (анимация типа step-by-step).
- Screen-record Claude Desktop на каждый день: создание папок, файлов, переход на Code-вкладку, Skills → Setup Co-Work.
- Закадровый голос владелец, на экране Claude в работе.
- Подпись в кадре «5 ДНЕЙ — С НУЛЯ В CLAUDE»
