# КАНОН: утренняя подборка «формат <agent>» (единый для ВСЕХ ботов агентства)

HARD-директива владелец ( + ): все агентские боты,
текущие и будущие, выдают утреннюю подборку ОДИНАКОВО — 1 в 1 как <agent> , от дизайна
HTML до формата каждой строки карточки. Свои форматы не выдумывать. Этот файл — единственный
источник правды; прозу в CLAUDE.md/промптах триггеров считать указателем сюда.

Механическая проверка: `scripts/digest_format_check.py` (exit 10 = формат нарушен, исправь
ДО выдачи). `send_morning_digest.py` сам печатает ⚠️-блок в сводку, если паки не по канону.

## 1. Deliverable (что уходит в чат)

Строго через `send_morning_digest.py` (с `NRR_CLIENT_DIR` для клиентских инстансов):

1. Сводка-сообщение (plain text, без markdown) — генерит скрипт.
2. Файл `reels_<YYYYMMDD>.html` — генерит скрипт из паков.
3. Файл `carousels_<YYYYMMDD>.html` — генерит скрипт (если карусели есть).

HTML руками НЕ собирать, CSS/шаблон НЕ менять, свои .html-форматы ЗАПРЕЩЕНЫ.
Клиентский бот: HTML из `out/` копирует в свой workspace и шлёт своим reply tool
(files=[...]) в рабочий чат клиента; после выдачи — `mark_shown.py`.

## 2. pack_NN.json — РИЛС (все ключи обязательны, непустые)

```json
{
  "author_username": "donor_three",
  "topic": "Суть темы одной фразой (кодворд ПРОБНЫЙ)",
  "code": "DaYMB7Ds9HB",            // shortcode; желателен (нужен mark_shown/protected)
  "url": "https://www.instagram.com/reel/DaYMB7Ds9HB/",
  "card": "...",                     // структура ниже, дословно
  "teleprompter": "...",
  "caption": "...",
  "editor_brief": "..."
}
```

### card — три блока, разделитель \n, шапки дословно:

```
МЕТРИКИ ОРИГИНАЛА (@handle): про:смотров=123106, ratio=×14.64 (медиана автора 8408), под:писчиков=31982, ком:ментов=1748, лайков=2346, длит=32с, возраст=18.6ч, скорость=6635/ч, score=110. PROTECTED (ком:менты, показы, скорость, ratio к медиане). ТОП РИЛС ДНЯ.
ПОЧЕМУ ВЗЯЛА: 2-4 предложения — почему этот рилс, чем формат ложится на клиента, куда ведёт кодворд.
ФОРМАТ ОРИГИНАЛА: язык, тип съёмки (talking head / сценка / подкаст-студия...), что переснимаем.
```

- Метрики в этом порядке и написании: `про:смотров= , ratio=× (медиана автора N), под:писчиков= , ком:ментов= , лайков= , длит=Nс, возраст=N.Nч, скорость=N/ч, score=N`. Если медианы/подписчиков нет в данных — поле честно `n/a` или ratio опускается (как у <agent>).
- `PROTECTED (...)` и `ТОП РИЛС ДНЯ / ТОП ПО ОБСУЖДЕНИЮ...` — только если реально protected/топ (из `_scored.json`).
- Двоеточие-маскировка табу-слов обязательна: `про:смотров`, `ком:ментов`, `под:писчиков`.
- Исключение REFERENCE-ONLY: off-niche protected-виралку можно включить для полноты картины БЕЗ телесуфлёра/капшена — editor_brief тогда начинается с `РЕФЕРЕНС-ONLY, телесуфлёр не готовила (причина)` + строка РЕФЕРЕНС.

### teleprompter
Речь клиента на камеру. Хук + ядро оригинала ДОСЛОВНО (рерайт ≤25%, только табу-слова/чужие
ники/чужой кодворд), голос строго клиента (его TONE_OF_VOICE.md). В конце проговариваемый CTA
с кодвордом. Валидатор хука: `hook_fidelity_check.py` (гоняется автоматически).

### caption
Отдельный текст-описание под рилс, ~300-450 знаков: крючок + value + CTA «напиши <КОДВОРД>».
НЕ пересказ телесуфлёра. Без длинных тире «—», без «не X, а Y» (style_check.py).

### editor_brief
ТЗ монтажёру по таймкодам:
```
0:00-0:03 Сцена: план, оверлей ДОСЛОВНО, подача. Хук дословно.
0:03-0:12 ...
...
САБТАЙТРЫ: ...
МУЗЫКА: ...
РЕФЕРЕНС: https://www.instagram.com/reel/<shortcode>/
```
Строка `РЕФЕРЕНС:` с url оригинала — обязательна.

## 3. pack_NN.json — КАРУСЕЛЬ

```json
{
  "type": "carousel",
  "author_username": "donor_six",
  "topic": "Суть карусели (кодворд УРОВНИ)",
  "url": "https://www.instagram.com/p/DagHC9-Dc82/",
  "card": "МЕТРИКИ ОРИГИНАЛА (@handle): ком:ментов=8, лайков=23, возраст=..., score=35.\nВЕРДИКТ: адаптировать | уникализировать | референс. Раскладка/визуал, тема, кодворд.\nПОЧЕМУ ПОКАЗЫВАЮ: 1-2 предложения.\nРЕФЕРЕНС: <url>",
  "caption": ""
}
```
`type: "carousel"` обязателен (по нему digest делит на 2 HTML). Телесуфлёр/ТЗ у каруселей нет.

## 4. meta.json (рядом с паками, обязателен)

```json
{
  "date_label": "YYYY-MM-DD",
  "intro": "...",
  "final": "..."
}
```

intro — скелет <agent> (порядок соблюдать, пустые секции опускать):
1. `🌅 Утренний niche-reels пакет` + счёт: «N рилсов + M каруселей» + напоминание структуры карточки.
2. PROTECTED: сколько рилсов/каруселей вошли как protected.
3. Отсевы с причинами (визуальный фильтр / off-niche / флоп / дубли) — поимённо @handle + shortcode.
4. `ТОП РИЛС ДНЯ:` @handle + shortcode + цифры + тема + кодворд. Рядом 1-2 сильных.
5. `ТОП КАРУСЕЛЬ ДНЯ:` аналогично.
6. Заметки дня (аномалии вотчлиста, cadence-флаги «постит реже раза в 2 дня»).
7. `ПОКРЫТИЕ:` строка покрытия скрейпа (X из N аккаунтов, упавшие).
8. CTA: «Выбери что берёшь, тапни блок копируется.»

final — 1-2 строки: «Это весь пак. Какие берёшь — напиши номера, отмечу в dedup.»

## 5. Правила поверх (действуют всегда)

- Кодворд у КАЖДОГО рилса свой, под тему и воронку клиента; в topic в скобках `(кодворд X)`.
- Объёмы: до 10 рилсов, карусели минимум 5 (до 10) — если пул позволяет; клиентские инстансы
  с маленьким вотчлистом отдают сколько есть, недобор честно называется в intro.
- Русский текст для людей: без «—», без «не X, а Y» (style_check.py гоняет триггер).
- Время в intro/сводке — МСК.
- Данные ТОЛЬКО из своего `NRR_CLIENT_DIR` (изоляция клиентов, HARD).
