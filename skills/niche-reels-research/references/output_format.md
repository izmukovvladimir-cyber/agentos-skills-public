# Формат выдачи в Telegram (утренний дайджест)

Пн-пт 08:00 МСК — последовательность сообщений в Telegram чат владельца. До 10 рилсов + каруселей минимум 5 (до 10). Если за окно <10 топов — шлю сколько есть.

## Структура потока (обновлено владелец)

```
INTRO (plain text)
└── РИЛС 1
    ├── Сообщение 1 — шапка+метрики+почему+формат  (PLAIN, НЕ копирка)
    ├── Сообщение 2 — Телесуфлёр                    (<pre> КОПИРКА)
    ├── Сообщение 3 — Капшен (описание под рилс)    (<pre> КОПИРКА)
    └── Сообщение 4 — ТЗ монтажёру                  (PLAIN, НЕ копирка)
└── РИЛС 2 ... до 10
FINAL (plain text)
```

**Под `<pre>` (копирка) идут ДВА блока: телесуфлёр + капшен.** Метрики и ТЗ — плоский текст (владелец их не вставляет дословно, только читает). Ссылка на оригинал — ВВЕРХУ сообщения 1. Референс для монтажёра — ВВЕРХУ ТЗ.

- **Телесуфлёр** = то, что владелец ГОВОРИТ на камеру (с проговариваемым CTA в конце).
- **Капшен** = короткое ОПИСАНИЕ ПОД РИЛС для вставки в Instagram (~300-450 симв): крючок по теме + value + CTA «статья». НЕ пересказ речи, отдельный текст. Маскировка двоеточием, без длинных тире. Кодовое слово только «статья» (под неё готова воронка).

## Финальное сообщение (plain)

```
ВСЁ. N рилсов готовы к записи.

Выбирай на сегодня. Тапни блок — копируется.

После записи одной строкой: «3, 7 взял» / «5 не подошёл» — апну state дедупликации, эти больше не покажу.
```

## Дополнительно: КАРУСЕЛЬ ПАРАЛЛЕЛЬНО

Для списочных форматов (5 ways / 5-day гайд / 5 ошибок) в дайджесте добавляется опциональный 4-й блок:

```
+ ПАРАЛЛЕЛЬНАЯ КАРУСЕЛЬ (опционально)

Темы:
Слайд 1 — хук «5 способов AI в контенте»
Слайд 2-6 — по одному способу
Слайд 7 — CTA «статья»

Если хочешь — собираю через carousel-reskinner.
```

владелец решает делать или нет. Дополнительная работа — только когда подтвердит.
